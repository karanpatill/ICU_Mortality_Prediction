## 2. Step-by-Step Submission Walkthrough

### Step 1: Open the Official Elsevier Editorial Manager Portal
1. Go to the official submission link:  
   👉 **https://www.editorialmanager.com/cbm/default2.aspx**
2. Click **"Register Now"** (if you don't already have an Elsevier account) or **"Login with ORCID / Elsevier Credentials"**.
3. Log in as an **Author**.

---

### Step 2: Start New Submission
1. In the Author Main Menu, click on **"Submit New Manuscript"**.
2. **Select Article Type:** Choose **"Full Length Article"** (or **"Research Paper"**). Click **Proceed**.

---

### Step 3: Attach Files (Upload the 3 Files)
Upload the files in this order using the dropdown file types:

| Item Type Dropdown | File to Select from your Computer |
|---|---|
| **Cover Letter** | Select `docs/ELSEVIER_CBM_COVER_LETTER.md` (or copy-paste text) |
| **Highlights** | Select `docs/ELSEVIER_CBM_HIGHLIGHTS.md` |
| **Manuscript** | Select `docs/Elsevier_CBM_Manuscript.docx` |

Click **Proceed**.

## 3. What Happens After Submission?

1. **Editorial Screening (1-3 days):** The Editor checks formatting and scope. Because we followed the exact CBM guidelines, it passes immediately to peer review.
2. **Under Review (3-4 weeks):** 2 to 3 international reviewers in clinical AI will review the paper.
3. **Decision & Revision:** You will receive constructive reviewer comments. We can easily respond to any reviewer questions together.
4. **Final Acceptance:** Once accepted, your paper gets a permanent **DOI on ScienceDirect, PubMed, and Scopus**, recognized globally!
